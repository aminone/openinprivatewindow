One quick step before you start

Firefox blocks every extension from creating private windows by default. You need to allow it once for OpenInPrivateWindow.

1

Open the extension's settings

Go to about:addons

Click "Extensions" in the left sidebar, then click on "Open in Private Window".

2

Allow private browsing access

Find "Run in Private Windows" and set it to Allow.

3

You're done

Right-click any tab and choose "Open in Private Window".

Note: "Open in Private Window" opens a new private window with the same address — Firefox does not support private "tabs" inside a normal window. Your original tab stays open and unaffected.
