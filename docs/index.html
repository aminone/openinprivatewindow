Open in Private Window

A small Firefox extension that reopens your current tab in a new Private Browsing window.

Get it on AMO (pending review) View on GitHub

Three ways to use it

Right-click

Right-click any tab and choose "Open in Private Window."

Toolbar icon

Click the icon in your toolbar for a one-click open.

Keyboard shortcut

Press Alt+Shift+P from anywhere.

What it does

Close the original tab

Optional setting - off by default. Closes the tab you triggered it from once the private window opens.

Strip tracking parameters

Optional setting - off by default. Removes ~100 known tracking query parameters (utm_source, fbclid, gclid, and more) from the URL before it opens.

Runs locally

No network requests, no data collection. Settings are stored only on your device.

Languages

Available in English and Persian (فارسی), including right-to-left layout.
